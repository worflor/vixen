Default leaf equations
These equations describe default timing and zero intro variation. Other opening durations use the canonical clock t=1+(x−1)·99/(openingEndpoint−1), with the chaos gate opening over the caller-space ramp. Forks compose actual leaf trajectories with the quintic handoff described above.
B(x) = x·exp(x/100) − 25·exp(−(x−42)²/32) − 38·exp(−(x−71)²/28)
S(t) = clipped quintic 6t⁵−15t⁴+10t³
G(x) = S((x−100)/ramp)
qᵢ(x,h) = (x−100)/scaleᵢ + phaseᵢ + directionᵢ·h
nᵢ = quintic interpolation between seeded counter values in [−1,1]
score = average of 48 nᵢ values
D(x,h) = strength·G(x)·2.2·tanh(contrast·score)
F(x,h) = B(x)·(1+D(x,h))
h(x) = latent + velocity·max(0,x−100)/100
Each seed changes scales, phases, directions and counter values. The vector h is continuous. For a fixed seed, noise joins, the entrance, and hypervector movement have matching value, slope and curvature: C² continuity. Rotating the explorer selects different directions through that same field; it does not regenerate it.
