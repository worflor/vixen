# Scope, limitations and release policy

Vixen provides deterministic progression fields, matching JavaScript/Python runtimes, native stabilization, configurable openings, admissible output policies, immutable timeline branches, replayable function guides and an offline instrument. Runtime dependencies are empty. Applications in README are integration possibilities, not evidence of production adoption.

## Mathematical and numerical boundaries

- Component findings and replayed certificates are not a whole-program composition certificate.
- Floating evaluation uses declared tolerances; integer hashes and seed derivation have separate exact contracts.
- Smooth joins do not imply strict monotonicity, band limitation, statistical independence or dynamical chaos.
- Narrow handoffs can amplify derivatives. Hard clipping can introduce corners; collapsed bands remove variation.
- Captured callbacks define sampled smooth approximations. They can miss features or overshoot, and are trusted developer code rather than a sandbox.
- Full influence or finite hash collisions can produce identical scalar futures from distinct seeds or decisions.
- Dimensions have no intrinsic semantic meanings. Calibration, fairness, rewards and authorization belong to the host application.

## Evidence and tooling

Executable acceptance, cross-port reports, scoped benchmarks and mathematical evidence live under `research/`. Historical observations do not automatically apply to the current runtime. Research tooling may require NumPy; runtime evaluation does not. Hosted CI requires working account infrastructure and is not a substitute for local, browser and installed-distribution acceptance.

## Release policy

MIT licensing, repository visibility and distribution publication are independent controls. Preserve owner-selected access settings; changes to visibility, registries, releases and hosted access require explicit approval. Review tracked history, package contents, documentation links, executable examples and evidence provenance before release. Keep credentials, viewer grants and machine-specific paths out of tracked content.
